# # 🚌 Bus Topology project

## 📌 Summary
This project demonstrates the design and implementation of a **Bus Topology Network** using **Cisco Packet Tracer**.  
I connected multiple PCs through a switch, configured static IP addresses, and verified connectivity using command‑line tools.  
To strengthen security, I disabled DHCP, applied MAC address filtering, and secured the switch by disabling unused ports.

---

## 🖥️ Network Design
- Multiple PCs connected to a switch  
- Bus topology structure created  
- Devices configured manually  

---

## 🔒 Security Implementation
- Static IP configuration (DHCP disabled)  
- MAC address filtering applied  
- Unused switch ports disabled  

---

## 📊 Output / Results
- Successful communication between PCs  
- Ping test verified connectivity  


## 🎯 What I Learned
- How to design and implement a simple bus topology in Cisco Packet Tracer  
- Importance of **manual IP configuration** for control and security  
- How **MAC address filtering** adds a layer of protection against unauthorized devices  
- Why disabling unused ports reduces attack surfaces   
---

This project helped me understand both **network design basics** and **security best practices**.  
It gave me hands‑on experience in configuring devices
